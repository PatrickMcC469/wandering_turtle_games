# Fonts

Both families are licensed under the SIL Open Font License 1.1, which permits
bundling them with a website. Files are the Latin subsets served by Google Fonts.

- **Baloo 2** — Ek Type. https://github.com/EkType/Baloo2
- **Source Sans 3** — Adobe / Paul D. Hunt. https://github.com/adobe-fonts/source-sans

Both are variable fonts: one file covers every weight, so `font-weight` in CSS
picks the weight without loading another file.
